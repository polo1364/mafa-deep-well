## 🎮 遊戲簡介

**數位深淵**是一款 Roguelike 風格的 Idle RPG 遊戲。在這個由數據構成的神秘世界中，你將扮演一名探索者，深入數位海洋的最深處。遊戲結合了自動戰鬥、裝備收集、迭代成長等多種玩法，提供豐富的遊戲體驗。

### 🌟 遊戲亮點

- 🎯 **自動戰鬥系統**：輕鬆掛機，享受成長樂趣
- ⚔️ **豐富的裝備系統**：8種品質、24種特殊詞綴
- 🔄 **迭代成長機制**：永久天賦、稱號系統
- 🏰 **副本挑戰**：4種副本類型、4個難度等級
- 👾 **怪物詞綴系統**：8種詞綴、動態戰鬥體驗
- 🗺️ **多區域探索**：4個區域、不同難度和獎勵
- 🎴 **卡牌被動加成**：8種卡牌系列，大幅提升戰力
- 🐾 **隨從戰鬥支援**：12生肖隨從提供額外屬性與技能
- 🌟 **黃道十二宮**：探索星座領域，收集元素碎片兌換黃道套裝
- 🎰 **賭博商人系統**：使用碎片賭博獲得隨機品質裝備
- 💠 **統一碎片系統**：5種碎片類型，清晰的圖示區分
- 📋 **每日任務獎勵**：每日5個任務，獲取豐富資源

每個星座都有3件專屬裝備（武器、防具、飾品），收集3件可獲得套裝效果。

**兌換方式**：
- 每件裝備需要 100個對應的💎元素碎片
- 元素碎片通過探索對應星座領域獲得
- 收集齊某個生肖的3件裝備可解鎖對應的生肖稱號

**套裝特色**：
- ✨ 每個星座套裝都有獨特的屬性加成

### 🔄 迭代系統

達到100級後可以進行迭代，重新開始但保留永久加成。

#### 迭代獎勵
- 🎁 **迭代點數（IP）**：根據等級、擊敗數、傳說裝備數量計算
- 🔷 **保留碎片**：根據迭代次數保留一定比例
- 🏆 **解鎖稱號**：每次迭代解鎖新稱號
- ✨ **天賦系統**：使用IP點亮天賦樹

#### 迭代重置內容
- ❌ 等級、經驗、金幣
- ❌ 所有裝備和物品
- ❌ 區域進度
- ❌ 臨時增益

#### 迭代保留內容
- ✅ 迭代點數（IP）
- ✅ 天賦樹
- ✅ 已解鎖稱號
- ✅ 部分碎片

#### 隨從系統特色

- **屬性加成**：提供永久性的屬性加成
- **技能系統**：擁有主動或被動技能
- **隨從升級**：可透過戰鬥獲得經驗升級
- **隨從裝備**：可裝備專屬道具，使用🌟隨從碎片升級
- **重複轉換**：重複獲得的隨從會自動轉換為🌟隨從碎片

### 🏪 商店系統

| 商店 | 貨幣 | 主要商品 |
|---|---|---|
| 普通商店 | 💰 金幣 | 藥水、卷軸、隨從、卡牌 |
| 碎片商店 | 🔷 裝備碎片 | 裝備寶箱、套裝寶箱、消耗品 |
| 卡牌碎片商店 | 🎴 卡牌碎片 | 各品質卡牌 |
| 🎰 賭博商人 | 🔷 裝備碎片 | 隨機品質裝備（200碎片/次，3天1次免費） |

### 📋 每日任務系統

每日任務是獲取資源的重要途徑，完成可獲得金幣、碎片和經驗值獎勵。

- **任務類型**：戰鬥類、收集類、探索類、成長類
- **每日數量**：5個任務，凌晨0點重置
- **刷新機制**：每天可免費刷新3次任務
- **完成度獎勵**：完成3個/5個任務有額外獎勵

### 🔨 強化系統

強化系統可以提升裝備的屬性，是後期提升戰力的重要途徑。

- **強化等級**：+0 到 +15
- **成功率**：+0~+5（100%）、+6~+10（90%）、+11~+15（70%）
- **失敗懲罰**：+11以上失敗會掉級

### 🎲 重鑄系統

重鑄系統可以重新生成裝備的屬性，用於優化裝備詞綴和屬性分配。

- **保留品質和類型**：重鑄後裝備品質和類型不變
- **重新生成屬性**：所有屬性點數和詞綴重新隨機生成
- **強化等級清零**：重鑄後強化等級歸零

### ♻️ 分解系統

分解系統可以將不需要的裝備轉換為🔷裝備碎片，是獲取碎片的重要途徑。

- **7種品質**：分解不同品質的裝備可獲得不同數量的碎片

### 💠 碎片系統

遊戲中有多種碎片類型，每種碎片有獨特的圖示和用途：

| 碎片類型 | 圖示 | 獲取方式 | 主要用途 |
|---------|------|----------|----------|
| **裝備碎片** | 🔷 | 戰鬥掉落、分解裝備 | 重鑄裝備、賭博商人 |
| **隨從碎片** | 🌟 | 重複隨從轉換 | 升級隨從裝備 |
| **卡牌碎片** | 🎴 | 重複卡牌轉換 | 兌換、升級卡牌 |
| **元素碎片** | 💎 | 黃道副本掉落 | 兌換黃道套裝 |
| **寵物碎片** | 🐾 | 分解寵物 | 寵物相關功能 |

**碎片獲取技巧**：
- 🔷 分解不需要的裝備可獲得大量裝備碎片
- 🌟 重複獲得的隨從會自動轉換為隨從碎片
- 🎴 重複獲得的卡牌會自動轉換為卡牌碎片
- 💎 探索黃道十二宮獲得元素碎片


### 💤 離線獎勵系統

離線時也能獲得獎勵，最長可累積48小時的離線收益。

- **經驗值和金幣**：基於角色等級計算，每小時獲得
- **裝備掉落**：每4小時掉落1件裝備
- **卡牌掉落**：每8小時掉落1張卡牌或碎片

### 💾 存檔系統

遊戲支持自動存檔和手動存檔，確保進度不會丟失。

- **自動存檔**：每30秒、關閉頁面、重要操作後自動存檔
- **手動存檔**：點擊「💾 存檔」按鈕手動存檔
- **導出/導入**：可導出存檔文件到本地，可導入存檔恢復進度

### 🎓 新手教學系統

遊戲內置10階段新手教學，幫助玩家快速上手。

- **教學流程**：角色創建 → 首次戰鬥 → 升級系統 → ... → 進階功能
- **新手獎勵**：500💰 + 20🔷 + 稀有裝備×1 + 隨機卡牌×1

### ⚡ 體力系統

體力（AP）是進行戰鬥和副本的必要資源。

- **最大體力**：100點（可透過天賦提升）
- **體力回復**：每2分鐘自動回復1點
- **消耗體力**：每次戰鬥消耗1點，副本消耗5-20點
