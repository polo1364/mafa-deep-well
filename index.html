❓ 如何遊玩

🚀 新手快速入門

歡迎來到數位深淵！只需5個步驟,立即開始你的冒險！

📝 步驟1: 創建角色

輸入你的角色名字,然後從9種職業中選擇一個。不用擔心,每個職業都很強,選一個你喜歡的就好!

💡 提示: 新手推薦系統架構師(坦克型)或數據科學家(均衡型)

⚡ 步驟2: 選擇技能

從10個技能中選擇1個作為你的專屬技能。技能分為攻擊型、防禦型和增益型。

💡 提示: 攻擊型技能適合快速推進,防禦型技能適合穩健玩法

▶️ 步驟3: 開始戰鬥

點擊主畫面左側的「▶️ 自動戰鬥」按鈕,遊戲會自動幫你戰鬥。你只需要坐著看日誌,等待勝利!

💡 提示: 戰鬥消耗1點體力(AP),體力會自動回復

🎒 步驟4: 穿上裝備

戰鬥勝利後,點擊「🎒 背包」查看獲得的裝備。選擇屬性更好的裝備,點擊「快速裝備」穿上!

💡 提示: 裝備品質從低到高: 灰 < 綠 < 藍 < 紫 < 橙 < 紅 < 金

🔄 步驟5: 重複循環

戰鬥 → 獲得裝備 → 變強 → 挑戰更強的敵人

就是這麼簡單!現在你已經掌握了遊戲的核心玩法!

🎯 接下來做什麼?

  • 每10場戰鬥會遇到Boss,獎勵更豐厚!
  • 達到26級後可以切換到更高級的區域
  • 點擊「💰 商店」購買藥水和道具
  • 點擊「🔨 鐵匠鋪」強化或分解裝備
  • 點擊其他Tab查看更多進階系統!

⚔️ 戰鬥與屬性

📊 角色屬性說明

屬性 說明
生命值 (HP) 你的血量,歸零就會死亡(但不會損失裝備)
攻擊力 (ATK) 決定你造成的傷害,越高越好
防禦力 (DEF) 減少受到的傷害
暴擊率 (CRIT) 觸發暴擊的機率(%)
暴擊傷害 (CRITDMG) 暴擊時造成的傷害倍率(%)
減傷 (DMG RED) 額外減少受到的傷害(%),上限75%
吸血 (LIFESTEAL) 攻擊時回復造成傷害的一定比例(%)
無視防禦 (ARMORPEN) 無視敵人一定比例的防禦(%)
幸運 (LUCK) 提升裝備掉落機率(%)
金幣獲取 (GOLD) 增加戰鬥獲得的金幣(%)

⚔️ 戰鬥流程

  1. 點擊「▶️ 自動戰鬥」消耗1點體力(AP)
  2. 自動遇到敵人並進入回合制戰鬥
  3. 玩家先攻擊 → 敵人反擊 → 循環直到一方HP歸零
  4. 勝利獲得經驗、金幣,有機率掉落裝備和消耗品
  5. 每10場戰鬥會遇到Boss,獎勵×3!

⚡ 體力系統

每次戰鬥消耗1點體力(AP),體力上限100點。

體力會自動回復,每2分鐘回復1點。

💡 提示: 也可以在商店購買能量藥水立即回復體力!

💀 死亡機制

如果你的HP歸零,你會死亡,但不會損失任何裝備或經驗!

死亡後,你的HP會自動回復到10%,可以繼續戰鬥。

✨ 裝備詞綴

高品質裝備會附帶前綴和後綴,提供強大的特殊效果!

🔥 前綴詞綴(武器專屬)
  • 熾熱的: 15%機率造成額外50%傷害
  • 閃電的: 20%機率連鎖傷害
  • 嗜血的: 擊殺回復15%最大生命
  • 神聖的: 10%機率造成200%傷害
🛡️ 後綴詞綴(防具專屬)
  • 守護: 致命傷只扣1血(30%機率)
  • 再生: 每5秒回復2%最大生命
  • 反射: 反彈10%傷害給敵人
  • 魔盾: 戰鬥開始獲得20%最大生命護盾

🎽 套裝系統

穿戴同名的套裝裝備可以觸發超強大的套裝效果!

2件套: 提供基礎屬性加成

4件套: 解鎖特殊效果(例如:暴擊連鎖、擊殺回血等)

💡 提示: 4件套的特殊效果非常強大,優先收集!

🔨 強化與分解

點擊「🔨 鐵匠鋪」可以強化或分解裝備。

⬆️ 強化裝備

消耗金幣和強化石,提升裝備的屬性值。

每次強化+1級,屬性提升5%

♻️ 分解裝備

將不需要的裝備分解成碎片和材料。

品質越高,獲得的碎片越多

隨從可以透過戰鬥升級,變得更強大。

🔄 迭代與天賦

🔄 什麼是迭代?

當你達到100級並完成所有主線Boss後,可以選擇迭代。

迭代後,你的等級、裝備、金幣會重置,但你會獲得永久的強化!

這是遊戲的核心長期目標!

🎁 迭代獎勵

💎 迭代點數(IP)

根據你的等級、擊敗數、傳說裝備數量等計算獲得的IP點數。

IP可以用來學習天賦,獲得永久加成!

💎 碎片保留

根據迭代次數,保留一定比例的碎片到下一輪。

第1次迭代保留10%,之後每次+5%,最高25%

🏆 迭代稱號

每次迭代解鎖新稱號,裝備後提供永久屬性加成。

例如:「初次迭代者」、「迭代大師」等

✨ 天賦系統

使用迭代點數(IP)在天賦樹中學習強大的永久被動效果!

⚔️ 戰鬥天賦
提升攻擊、暴擊、暴傷
🛡️ 防禦天賦
提升生命、防禦、減傷
💰 資源天賦
增加金幣、經驗、掉落
✨ 特殊天賦
解鎖特殊能力

💡 提示: 天賦效果永久生效,即使迭代也不會消失!

🏆 稱號系統

完成特定成就解鎖稱號,裝備後獲得永久屬性加成!

稱號分為多個系列:

  • 🔄 迭代者系列: 完成迭代解鎖
  • ⚔️ 戰鬥系列: 擊敗大量敵人解鎖
  • 💰 財富系列: 累積金幣解鎖
  • 🗺️ 探索系列: 探索區域解鎖

⚠️ 迭代注意事項

迭代將重置: 等級、經驗、金幣、所有裝備和物品、區域進度

迭代保留: 迭代點數、天賦、稱號、部分碎片
